# SO-101 price check

What it costs to build an [SO-101](https://github.com/TheRobotStudio/SO-ARM100) robot arm in the US, one arm or a leader + follower pair, with a link to the shop for every price and the date it was checked.

The full write-up, with servo gear ratios, kits and setup problems, is the [SO-101 parts list and cost guide](https://robotusecases.com/guides/so-101-parts-list-cost?utm_source=github). That page also has an email price check, so you can hear when these numbers move.

## What it costs at today's retail prices

We priced the same parts new on Oct 30, 2026. One follower arm came to $131.69 and a leader + follower pair came to $254.48, before shipping, tax and a screwdriver set. That uses [WowRobo](https://shop.wowrobo.com)'s STS3215 servos at $15.99 each ($74.95 for a 5-pack) and the Amazon listings in the table above.
